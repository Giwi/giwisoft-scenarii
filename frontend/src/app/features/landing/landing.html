Quick start

Write a scenario

name: API health check
schedule: "*/5 * * * *"
base_url: https://api.example.com

steps:
  - name: Health endpoint
    action: http.get
    url: /health
    expect:
      status: 200
      response_time_under: 3000

Run it

# one-off run
npx scenarii --once scenarios/health.yml

# server + dashboard + scheduler
npx scenarii server -p 3000

The first start prints a generated admin password in the logs. Configure OIDC in settings.yml to sign in with SSO instead.
